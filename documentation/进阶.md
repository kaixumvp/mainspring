# 进阶：Ports / 权限与 HITL / 重放 / 事件流式

> 进阶页。「框架定义端口、宿主实现」——`mainspring.ports` 是框架↔宿主的全部契约，一页看全；本页再讲四个最常用的进阶场景。

## Ports 一览

| 端口 | 作用 | 默认/零配置替代 |
|------|------|-----------------|
| `LLMGateway` / `StreamingLLMGateway` | 模型调用（`chat` / `chat_stream`） | `LiteLLMGateway`；离线用 `ReplayGateway` |
| `PermissionChecker` + `PermissionContext` | 执行前授权 | 纯逻辑 `check_permission()` |
| `EventSink` | 运行时事件出口（`RuntimeEvent`） | 无（不注入即静默） |
| `Checkpointer` | 暂停/恢复快照 | `InMemoryCheckpointer`；官方 SQLite/Redis/PG |
| `ContextManager` | Decide 前压缩历史 | `SlidingWindowContext` |
| `LongTermMemory` / `Knowledge` / `Retriever` | 长期记忆 / RAG 召回 | 无（注入才启用，缺失静默跳过） |
| `Metrics` / `Tracer` | 指标 / 链路（`opentelemetry-api` 可选） | no-op |
| `Judge` | 离线评测打分 | `HeuristicJudge` |

`RuntimeDeps` 只要求 `llm`，其余按需注入。

## 权限与 HITL（人工审批暂停/恢复）

不信任 LLM 的选择：`execute` 节点在**执行前**强制授权，deny 优先；`admin` 资源或 `requires_approval` 且未获批准时，run **真正暂停**而不是返回字符串继续跑。

```python
from mainspring.ports import PermissionContext, PermissionDecision, check_permission

class MyChecker:                      # 实现 PermissionChecker 协议
    def check(self, ctx, action, resource_type, resource_id,
              resource_permission="read", requires_approval=False, approved=None):
        return check_permission(ctx, action, resource_type, resource_id,
                                resource_permission=resource_permission,
                                requires_approval=requires_approval,
                                approved=approved)

deps = RuntimeDeps(
    llm=llm,
    permission_checker=MyChecker(),
    permission_context=PermissionContext(permission_codes={"run:execute"}),  # 宿主从 RBAC 数据构建
    checkpointer=InMemoryCheckpointer(),                                     # resume 必需
)

context = RunContext(run_id="run-1", session_id="s1")   # 显式 run_id，便于 resume
result = await runtime.run(definition, "把 100 元转给 alice", context, deps)
# result.status == "awaiting_human"
# result.pending_approvals == [{"resource_type": "tool", "resource_id": "...", "action": "transfer"}]

resumed = await runtime.resume(
    definition, "run-1",                            # 同一 run_id 续跑
    ["tool_transfer"],                              # 批准的资源 ID 列表
    deps,
)
# resumed.status == "completed"
```

判定顺序：**admin 绕过 → `run:execute` 功能码 → deny 优先 → read 默认放行 → grant 白名单 → 高危审批**。`Checkpointer` 保存的是 pre-execute 快照（不含工具输出，避免泄密），`resume` 精确重跑被拦的那一步。持久化后端见 [框架 README Checkpointer 段](../README.md)。

## 确定性重放与评测

`RecordingGateway` 录制一次 run 的全部 LLM 响应，`ReplayGateway` 离线重放——**同一 run 复现同一结果**，这是离线评测和回归的底座：

```python
from mainspring.llm.replay import RecordingGateway, ReplayGateway, dump_recording, load_recording
from mainspring.evaluation import GoldenSet, run_evaluation

recording = RecordingGateway(litellm_gateway)      # 包一层真实网关
result = await runtime.run(definition, task, context, RuntimeDeps(llm=recording))
dump_recording(recording.recorded, "runs/task1.json")

# 离线：零成本回归
replay = ReplayGateway(load_recording("runs/task1.json"))
same = await runtime.run(definition, task, context, RuntimeDeps(llm=replay))
assert same.result == result.result
```

`GoldenSet` 批量跑任务集，`Judge`（LLM-as-judge 或 `HeuristicJudge`）打分。流式也重放：`ReplayGateway` 把每个录制响应合成为单个 chunk，流式消费方离线同样确定。

## 事件与流式

```python
async def sink(event):                            # EventSink：框架只出数据，传输宿主做
    if event.event == "message.delta":
        print(event.data["delta"], end="", flush=True)   # token 级打字机

deps = RuntimeDeps(llm=LiteLLMGateway(...), event_sink=sink)
```

事件类型：`run.started` / `step.completed` / `message.delta` / `run.completed` / `run.failed` / `run.awaiting_human` / `run.approved` / `run.rejected`。

流式自动启用条件：网关实现 `chat_stream` **且**注入了 `event_sink`；否则静默回退 `chat()`，零成本。注意 `message.delta` 是**临时性**事件——Decide 重试会从头重流，消费方应增量渲染、只把折叠后的最终结果当权威。

## 上下文治理

长任务历史无限增长会爆窗口。`ContextManager` 端口在每次 Decide 前压缩历史，**被丢弃的轮次永久移除**：

```python
from mainspring import RuntimeConfig

definition = AgentDefinition(model="...",
                             runtime=RuntimeConfig(max_history_messages=40))  # 零配置滑窗
deps = RuntimeDeps(llm=llm, context_manager=MySummarizingContext(llm))       # 自定义摘要策略
```

默认 `SlidingWindowContext`：保留头部 system 消息 + 最新窗口、切点跳过孤立 tool 消息、超长工具结果就地截断。
