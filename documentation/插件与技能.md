# 插件与技能

> 第 3 页。Tool / Skill / Knowledge 在框架里是**同一种东西**：`Plugin`。一张 `PluginManifest` 声明「是什么」，`invoke(ctx, **kw)` 定义「怎么做」；`execute` 节点对它们一视同仁。

## Plugin 协议

```python
# mainspring.ports（契约集中地）
class PluginManifest(BaseModel):
    name: str                     # 裸名，注册表主键
    resource_id: str | None       # 稳定资源 ID（权限/审计用），缺省回退 name
    version: str = "1"
    kind: str                     # tool | skill | knowledge | model | memory | node
    description: str = ""
    parameters: dict              # OpenAI 风格 JSON Schema（LLM 看到的参数）
    permission: str = "read"      # read | write | admin
    requires_approval: bool = False
    dependencies: list[str] = []
    tags: list[str] = []

class Plugin(Protocol):
    kind: str
    manifest: PluginManifest
    async def invoke(self, ctx: InvokeContext, **kw) -> Any: ...
```

声明与实现分离：`manifest` 描述能力（给 LLM 的 schema、给权限系统的最小权限面），`invoke` 执行能力。工具见 [开发工具](./开发工具.md)，本页讲 Skill 与注册机制。

## Skill：四种形态

Skill 是 `kind="skill"` 的插件，按 `type` 分四种形态：

```python
from mainspring.plugins.base import PluginManifest
from mainspring.skills.prompt_skill import PromptSkill
from mainspring.skills.function_skill import FunctionSkill
from mainspring.skills.agent_skill import AgentSkill
from mainspring.skills.flow_skill import FlowSkill
from mainspring.skills.base import build_skill  # 或按 type 分发的工厂

# prompt：模板渲染（{{key}} 占位符），渲染结果作为参考资料注入对话，不执行代码
PromptSkill(PluginManifest(name="refund_policy", kind="skill"),
            {"template": "退款政策：7 天无理由。用户上下文：{{memory_ctx}}"})

# function：执行一段 Python（def run(**kw) -> str）
FunctionSkill(PluginManifest(name="add", kind="skill"),
              {"source": "def run(**kw):\n    return str(int(kw['a']) + int(kw['b']))"})

# agent：调子 Agent（宿主注入 run_subagent 回调；递归深度由 max_subagent_depth 封顶）
AgentSkill(PluginManifest(name="escalate", kind="skill"),
           {"agent_ref": "agent_escalation"}, run_subagent=my_subagent_runner)

# flow：多步流程（宿主注入 run_flow 回调）
FlowSkill(PluginManifest(name="report", kind="skill"),
          {"graph_spec": {}}, run_flow=my_flow_runner)
```

**FunctionSkill 默认子进程沙箱**（全新解释器 + 受限 builtins + 超时），`body.sandbox = "inline"` 显式退回进程内 `exec`（更快，但**不是安全边界**，仅限可信作者）。

## 注册与解析

```python
from mainspring.plugins.registry import PluginRegistry

registry = PluginRegistry()
registry.register(my_plugin)          # 三键索引：裸名 / kind:name@version / function_name
registry.register_tool(my_tool)       # 糖：内部用 ToolAsPlugin 适配成 Plugin
registry.get("calculator")            # 三种键都能查
registry.get("tool:calculator@1")
registry.to_openai_schema()           # 组装 function-calling schema
await registry.invoke("calculator", ctx, expression="3*8")
```

**function_name 命名空间**：`tool` 用裸名（`calculator`），其它 `kind` 加前缀（`skill_refund_policy`），避免 function-calling 撞名。LLM 返回的 `tool_call.name` 即 `function_name`，`registry.get()` 直接反查。

引用语法（跨 Agent 装配 / 依赖声明用）：

```python
from mainspring.plugins.manifest import parse_ref, format_ref

parse_ref("skill:refund@1.2.0")       # PluginRef(kind="skill", name="refund", version="1.2.0")
format_ref("skill", "refund", "1.2.0")
```

## 装配进 Agent

```python
from mainspring import AgentDefinition

definition = AgentDefinition(
    model="deepseek-chat",
    plugins=registry.all(),           # 或 registry.resolve(["calculator", "skill:refund"])
)
```

`AgentRuntime._build_registry` 只认 `Plugin` 协议——无论插件从代码写死、DB 装配还是远程加载，宿主把最终列表放进 `AgentDefinition.plugins` 即可。框架对来源一无所知，这是业务层 `db_plugin_loader` 的接入点。
