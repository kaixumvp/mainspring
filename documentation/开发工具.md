# 开发工具：`@tool` 装饰器

> 第 2 页。把一个**类型化函数**直接变成 Agent 可调用的工具：签名自动生成参数 JSON Schema，docstring 即描述，每次调用先校验再执行。比手写 `BaseTool` 少 90% 样板。

## 最小例子

```python
from mainspring.tools.decorator import tool

@tool
def add(a: int, b: int) -> str:
    """两个整数相加。"""
    return str(a + b)
```

等价于手写一个 `BaseTool`（`name` 取函数名、`description` 取 docstring、`parameters` 由签名生成）。装配时与手写工具完全一致：

```python
from mainspring.plugins.base import ToolAsPlugin
from mainspring.plugins.registry import PluginRegistry

registry = PluginRegistry()
registry.register(ToolAsPlugin(add))
# 或 registry.register_tool(add) —— ToolAsPlugin 的糖
```

## 签名 → JSON Schema

装饰器用 Pydantic 从函数签名生成 OpenAI 风格的 `parameters`：

| Python 写法 | 生成的 Schema |
|-------------|---------------|
| 无默认值 `a: int` | 进 `required` |
| 有默认值 `b: int = 2` | 不进 `required`，带 `default` |
| `Annotated[int, Field(description="...")]` | 带参数描述 |
| `Literal["a", "b"]` | `enum` |
| `list[str]` / `dict[str, int]` | `array` / `object` 嵌套 |

```python
from typing import Annotated, Literal
from pydantic import Field

@tool
def search(query: Annotated[str, Field(description="搜索关键词")],
           source: Literal["web", "doc"] = "web") -> str: ...
```

## 权限与描述覆盖

```python
@tool(name="transfer_money", description="转账（高危）", permission="admin")
def transfer(amount: float, to: str) -> str:
    return f"已向 {to} 转账 {amount} 元"
```

`permission` 取值 `read | write | admin`，映射到 `PluginManifest.permission`——`admin` 资源在无审批时会让 `execute` 节点返回 `awaiting_human`（见 [进阶：HITL](./进阶.md)）。装饰后的函数仍可从 `tool.fn` 取回原函数。

## 执行模型

- **同步函数**跑在 worker 线程（`asyncio.to_thread`），不阻塞事件循环；**异步函数**内联 await。
- 每次调用经 `validate_call` 校验 + 类型强制：LLM 传来的 `"5"` 会变成 `5`。
- 校验失败 / 函数抛异常 → `ToolResult(success=False, error=...)`，**不打断**运行循环（错误作为工具结果回给 LLM）。
- 返回 `str` / `dict` / `ToolResult` 都能正确折叠；`dict` 会被序列化为 JSON 字符串。

## 与手写 `BaseTool` 的关系

`@tool` 是 `BaseTool` 的一个实现（`FunctionTool`），不是替代。需要动态参数、自定义 `run()` 签名、或非函数形态的工具时仍手写 `BaseTool`（见框架 README「开发自定义 Tool」）。两条路产出同一种东西，`ToolAsPlugin` 统一适配。
