# 快速上手（3 分钟）

> 目标：**零 API key、10 行代码跑通一个带工具调用的 Agent 循环**，再顺手起一个可视化 DevUI。
> 完整 API 速查见 [框架 README](../../application/mainspring/README.md)，能力路线见 [版本规划](./版本规划.md)。

## 1. 安装

```bash
pip install mainspring          # Python >= 3.11
```

## 2. 离线跑通（无需 API key）

下面这段**不联网、不调任何真实 LLM**——用 `ReplayGateway` 把两轮 LLM 响应脚本化：第一轮让模型调 `calculator` 工具，第二轮收尾回答。10 行核心代码：

```python
import asyncio
from mainspring import AgentDefinition, AgentRuntime, RunContext, RuntimeDeps
from mainspring.llm.replay import ReplayGateway
from mainspring.plugins.registry import PluginRegistry
from mainspring.ports import LLMResponse, ToolCall
from mainspring.tools.registry import build_default_registry

registry = PluginRegistry()
for tool in build_default_registry().all():
    registry.register_tool(tool)

llm = ReplayGateway([
    LLMResponse(tool_calls=[ToolCall(id="c1", name="calculator",
                                     arguments={"expression": "3*8+100"})]),
    LLMResponse(content="结果是 124"),
])

async def main():
    result = await AgentRuntime().run(
        AgentDefinition(model="offline-demo", plugins=registry.all()),
        "计算 3*8+100", RunContext(), RuntimeDeps(llm=llm),
    )
    print(result.status, result.result)   # completed, 结果是 124

asyncio.run(main())
```

发生了什么：`decide` 节点拿到脚本化的工具调用 → `execute` 节点真正执行了 `calculator("3*8+100")` → 第二轮 `decide` 收尾。这就是 `Decide → Execute → Observe` 循环的全部。

## 3. 接真实 LLM（只换一行）

```python
from mainspring.llm.litellm_gateway import LiteLLMGateway

llm = LiteLLMGateway(model="deepseek-chat", api_key="sk-...")
# 其余代码不变：deps 只要求 llm 这一个端口
```

## 4. 一行起 DevUI（可视化运行过程）

```bash
mainspring dev        # 打开 http://127.0.0.1:8765
```

页面里点「运行」：左侧是 steps 时间线，右侧逐 token 流出 `message.delta`，中间会弹出一次**人工审批卡**（demo 里有个 `permission="admin"` 的转账工具），点「批准全部」后同一次 run 继续跑完。全程离线、无 API key。详见 [DevUI](./DevUI.md)。
